# PERSEPOLIS Standalone
Standalone Telegram Mini App rebuild. Node.js + Express, no Apps Father dependency.

## Run
Node.js 20+
1. Copy `.env.example` to `.env`
2. Set `BOT_TOKEN` and `ADMIN_TELEGRAM_IDS`
3. `npm install`
4. `npm start`

This is a fresh rebuild; Apps Father users/balances are not imported because no DB export was available.
Use HTTPS in production.
